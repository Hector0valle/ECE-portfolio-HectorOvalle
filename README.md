# Hector Ovalle Engineering Portfolio

This site is built to be deployed on GitHub Pages.

## To publish

1. Create a public repository on GitHub.
2. If you want the site URL to be `https://YOUR-USERNAME.github.io/`, name the repository exactly:

   `YOUR-USERNAME.github.io`

3. Upload every file in this folder to the root of that repository.
4. Wait a minute or two for GitHub Pages to deploy.

If you instead use a different repository name, GitHub Pages can still host the site, but the URL will usually be:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
